At a glance

What it is
SQL to ER Diagram is a free, open-source browser tool that turns a PlantUML entity or class diagram into an interactive entity-relationship (ER) diagram.
Input
A PlantUML entity or class diagram: an @startuml … @enduml block.
Output
An interactive ER diagram you can rearrange, then export as PNG, SVG, Mermaid, DBML or PlantUML, or share as a link.
Cost
Free. MIT-licensed open source. No account or signup.
Privacy
Runs entirely in your browser. The schema is never uploaded, and share links carry the diagram in the URL fragment, which is not sent to a server.
Limits
It never connects to your database itself: you paste schema text, or run one read-only catalog query in your own client and paste the result. There are no accounts, so there is no real-time multi-user editing; diagrams are kept in your browser, as a saved file, or as a share link. Layout stays smooth at around 300 tables.

How it works

  1. Copy your PlantUML @startuml … @enduml block.
  2. Paste it into the viewer — PlantUML is auto-detected.
  3. Each entity / class becomes a table; relationship lines become relations.
  4. Drag to arrange, then export PNG/SVG or convert to Mermaid/DBML.

Example

Paste PlantUML like this:

@startuml
entity authors {
  * id : int
  name : varchar
}
entity books {
  * id : int
  author_id : int
  title : varchar
}
authors ||--o{ books
@enduml

…and the viewer draws two tables with a relation from books → authors. Try it with your own →

Guide

The usual way to view PlantUML is a round trip: the jar and Java, or a company PlantUML server, or the public server — which means sending your diagram text to something. This viewer renders entity and class diagrams entirely in the browser: paste the @startuml … @enduml block, and the diagram appears with zero requests.

That privacy property is the reason most people bookmark this page — the diagram text for an internal database schema is itself sensitive, and "paste it into a public web service" is a non-starter in a lot of organisations. Here the paste is the whole story: no upload endpoint exists to receive it.

Supported input: entity and class blocks with typed fields, * mandatory-field markers, and crow's-foot relationship connectors (||--o{ etc.). Skinparams and themes are ignored. What you get that a static render doesn't give you: drag to rearrange, hide tables to focus, and export PNG/SVG at whatever arrangement looks best — or convert the schema to Mermaid or DBML if your docs platform changed under you.

Why use it

  • Private: everything runs in your browser — nothing is uploaded or stored on a server.
  • No server, no Java — renders instantly in the browser, unlike a PlantUML render pipeline.
  • Interactive: drag tables, auto-arrange, hide noise, add notes, and manually link columns.
  • Export a high-res PNG, vector SVG, or the schema as Mermaid / DBML / PlantUML code.
  • Free & open source — no account, no sign-up.

FAQ

Do I need a PlantUML server or Java to view a diagram?

No — paste the PlantUML text and it renders directly in your browser as an interactive diagram you can edit and export.

Which PlantUML diagrams can I view?

Entity-relationship and class diagrams: entity / class blocks with fields, plus relationship connectors like ||--o{.

Is my schema uploaded anywhere?

No. Everything runs locally in your browser — your schema is never uploaded to or stored on any server.

Can I export the diagram?

Yes — export a high-resolution PNG or vector SVG, copy the schema as Mermaid, DBML or PlantUML, or share a link that encodes the whole diagram in the URL.

Is it free?

Yes. It is completely free and open source, with no account or sign-up required.
